
# Predictive Analytics Using Historical Data

## 📌 Project Overview

This project uses historical sales data to build a machine learning model that predicts future sales.

The project demonstrates data preprocessing, exploratory data analysis, visualization, machine learning, model evaluation, and future sales prediction.

## 🎯 Objectives

- Analyze historical sales data
- Identify sales trends
- Preprocess and clean the dataset
- Build a predictive machine learning model
- Evaluate model performance
- Predict future sales based on advertising and customer data
- Visualize actual and predicted sales

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- GitHub

## 🤖 Machine Learning Model

The project uses **Linear Regression** to predict sales.

### Input Features

- Advertising
- Customers

### Target Variable

- Sales

## 📊 Model Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 🔮 Future Prediction

The trained model was used to predict future sales based on new advertising expenditure and expected customer count.

Example input:

- Advertising: ₹28,000
- Customers: 700

The model generated a future sales prediction based on these inputs.
